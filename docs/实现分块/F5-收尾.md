### 4.1 新建 `src/utils/format.js`

```js
/*
【功能】前端公共格式化函数
【作用】四个页面都要显示时间、大小、状态文案，集中一处避免各写一份还不一致
【输入】见各函数参数
【输出】格式化后的字符串
【怎么用】import { fmtTime, fmtSize, statusText } from '@/utils/format'
【例子】fmtTime('2026-11-09T13:11:33') -> '2026-11-09 13:11'
*/

const p = (n) => String(n).padStart(2, '0')

export function fmtTime(v) {
  if (!v) return '—'
  const d = new Date(v)
  if (Number.isNaN(d.getTime())) return String(v)
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())} ${p(d.getHours())}:${p(d.getMinutes())}`
}

export function fmtSize(bytes) {
  if (bytes === null || bytes === undefined) return '—'
  if (bytes < 1024) return `${bytes} B`
  if (bytes < 1024 * 1024) return `${(bytes / 1024).toFixed(1)} KB`
  return `${(bytes / 1024 / 1024).toFixed(2)} MB`
}

// 后端 status 只有四种取值
export const STATUS_MAP = {
  PENDING: { text: '排队中', type: 'info' },
  RUNNING: { text: '审计中', type: 'warning' },
  DONE: { text: '已完成', type: 'success' },
  FAILED: { text: '失败', type: 'danger' },
}

export function statusText(s) {
  return STATUS_MAP[s]?.text || s || '—'
}

export function statusType(s) {
  return STATUS_MAP[s]?.type || 'info'
}
```

> 改造点：F1/F2/F3 里如果有自己写的 `fmt()`，换成 `import { fmtTime } from '@/utils/format'`，删掉重复实现。

### 4.4 构建

```powershell
cd F:\毕业设计\audit-web
npm run build
```

成功后会生成 `dist/`（`index.html` + `assets/*.js`、`*.css`）。

如果报错，先看是不是这三类：

| 报错 | 原因 | 处理 |
|---|---|---|
| `Rollup failed to resolve import "@/..."` | 别名没配 | 检查 `vite.config.js` 的 `resolve.alias` |
| `Unexpected token` / `is not defined` | 用了没装的东西（如 `dayjs`） | 要么装，要么改成原生 `Date` |
| 产物里图片 404 | 静态资源路径写死 `/src/...` | 用 `import` 或放 `public/` |

### 4.5 整合成单 jar（答辩交付形态）

```powershell
# 1. 清掉后端旧的静态资源
Remove-Item F:\毕业设计\graduation-audit\src\main\resources\static\* -Recurse -Force -ErrorAction SilentlyContinue

# 2. 把 dist 里的内容拷进去（注意是内容，不是 dist 文件夹本身）
Copy-Item F:\毕业设计\audit-web\dist\* F:\毕业设计\graduation-audit\src\main\resources\static\ -Recurse -Force

# 3. 打包
cd F:\毕业设计\graduation-audit
mvn clean package -DskipTests

# 4. 运行（换到任何装了 JDK 21 + MySQL 的机器都能跑）
java -jar target\graduation-audit-0.0.1-SNAPSHOT.jar
```

打开 `http://localhost:8080`，应该直接是前端首页（不是 Whitelabel）。

> **路由必须是 hash 模式**（F0 已用 `createWebHashHistory`），否则打包后刷新 `/tasks` 会 404。

## 6. 卡住怎么办

| 症状 | 原因 | 处理 |
|---|---|---|
| 打包后首页白屏，控制台 `Failed to load module script` | `dist/index.html` 里的资源路径是绝对 `/assets/...`，但静态资源被放在别的位置 | 确认 `vite.config.js` 没有把 `base` 改成奇怪的值（默认 `'/'` 就行） |
| 打包后点菜单 404 | 用了 history 路由 | 必须 `createWebHashHistory` |
| 8080 打开是 Whitelabel | 静态资源没拷对 | `static/` 下应该直接是 `index.html`，不是 `static/dist/index.html` |
| 接口 404（`/api/audit` 不存在） | 打包后同源，但后端没这个映射 | 检查后端是否 `mvn package` 的是最新代码 |
| `npm run build` 卡住不动 | 内存不够或 watch 遗留进程 | 关掉 `npm run dev` 再构建 |
