## 4. 操作步骤

### 4.1 覆盖 `src/views/TaskListView.vue`

```vue
<!--
【功能】展示全部审计任务，带状态标签、代码块进度，并支持点击进入报告
【作用】历史任务可回看，答辩演示不必现场调模型
【输入】无（从 /api/audit/tasks 拉取）
【输出】表格；行点击跳转 /#/report/:id
【怎么用】左侧菜单点"任务列表"
【例子】看到 BadDemo.java / java / 完成 / 3/3，点它进入报告页
-->
<template>
  <div class="page">
    <el-card shadow="never">
      <template #header>
        <div class="card-header">
          <span>审计任务<el-tag v-if="runningCount" type="warning" class="ml"> {{ runningCount }} 个进行中 </el-tag></span>
          <div>
            <el-switch v-model="autoRefresh" active-text="自动刷新" class="mr" />
            <el-button :loading="loading" @click="load">刷新</el-button>
          </div>
        </div>
      </template>

      <el-table
        v-loading="loading"
        :data="tasks"
        stripe
        highlight-current-row
        empty-text="还没有审计记录，去「上传审计」传一个文件"
        @row-click="openReport"
        class="table"
      >
        <el-table-column prop="id" label="ID" width="70" />
        <el-table-column prop="fileName" label="文件名" min-width="200" show-overflow-tooltip />
        <el-table-column prop="language" label="语言" width="90">
          <template #default="{ row }">
            <el-tag :type="row.language === 'java' ? 'warning' : 'success'" size="small">
              {{ row.language }}
            </el-tag>
          </template>
        </el-table-column>
        <el-table-column label="状态" width="110">
          <template #default="{ row }">
            <el-tag :type="statusType(row.status)" size="small">
              {{ statusText(row.status) }}
            </el-tag>
          </template>
        </el-table-column>
        <el-table-column label="进度" width="160">
          <template #default="{ row }">
            <el-progress
              :percentage="percent(row)"
              :status="row.status === 'FAILED' ? 'exception' : undefined"
              :stroke-width="10"
            />
            <span class="chunk">{{ row.doneChunks }}/{{ row.totalChunks }}</span>
          </template>
        </el-table-column>
        <el-table-column label="创建时间" width="150">
          <template #default="{ row }">{{ fmt(row.createdAt) }}</template>
        </el-table-column>
        <el-table-column label="耗时" width="90">
          <template #default="{ row }">{{ cost(row) }}</template>
        </el-table-column>
        <el-table-column label="操作" width="110" fixed="right">
          <template #default="{ row }">
            <el-button link type="primary" @click.stop="openReport(row)">看报告</el-button>
            <el-tooltip v-if="row.status === 'FAILED'" :content="row.errorMsg || '未知错误'" placement="top">
              <el-button link type="danger" @click.stop>原因</el-button>
            </el-tooltip>
          </template>
        </el-table-column>
      </el-table>
    </el-card>
  </div>
</template>

<script setup>
import { computed, onBeforeUnmount, onMounted, ref, watch } from 'vue'
import { useRouter } from 'vue-router'
import { ElMessage } from 'element-plus'
import api from '@/api'

const router = useRouter()

const tasks = ref([])
const loading = ref(false)
const autoRefresh = ref(true)
let timer = null

const runningCount = computed(() => tasks.value.filter((t) => t.status === 'RUNNING').length)

const STATUS = {
  PENDING: { text: '待处理', type: 'info' },
  RUNNING: { text: '审计中', type: 'warning' },
  DONE: { text: '完成', type: 'success' },
  FAILED: { text: '失败', type: 'danger' },
}
const statusText = (s) => STATUS[s]?.text || s
const statusType = (s) => STATUS[s]?.type || 'info'

function percent(row) {
  if (row.status === 'FAILED') return 100
  if (!row.totalChunks) return row.status === 'DONE' ? 100 : 0
  return Math.min(100, Math.round((row.doneChunks / row.totalChunks) * 100))
}

function fmt(v) {
  if (!v) return '-'
  const d = new Date(v)
  const p = (n) => String(n).padStart(2, '0')
  return `${p(d.getMonth() + 1)}-${p(d.getDate())} ${p(d.getHours())}:${p(d.getMinutes())}`
}

function cost(row) {
  if (!row.createdAt || !row.finishedAt) return '-'
  const s = Math.round((new Date(row.finishedAt) - new Date(row.createdAt)) / 1000)
  return s < 60 ? `${s} 秒` : `${(s / 60).toFixed(1)} 分`
}

async function load(silent = false) {
  if (!silent) loading.value = true
  try {
    tasks.value = await api.tasks()
  } catch (e) {
    if (!silent) ElMessage.error(e.message)
  } finally {
    loading.value = false
  }
}

function openReport(row) {
  router.push(`/report/${row.id}`)
}

// 轮询：有 RUNNING 且开关打开时才每 3 秒拉一次，避免空转
function syncTimer() {
  if (timer) { clearInterval(timer); timer = null }
  if (autoRefresh.value && runningCount.value > 0) {
    timer = setInterval(() => load(true), 3000)
  }
}

watch([runningCount, autoRefresh], syncTimer)

onMounted(async () => {
  await load()
  syncTimer()
})

onBeforeUnmount(() => timer && clearInterval(timer))
</script>

<style scoped>
.page { max-width: 1180px; margin: 0 auto; }
.card-header { display: flex; justify-content: space-between; align-items: center; }
.ml { margin-left: 8px; }
.mr { margin-right: 12px; }
.table { cursor: pointer; }
.chunk { font-size: 12px; color: #909399; }
</style>
```

## 5. 验收打勾清单

- [x] 打开 `/#/tasks`，表格里能看到 F1 传过的任务（实测 11 条，id 1–11）
- [x] 顺序是 id 从大到小（最新的在最上面，首行为 11）
- [ ] 状态列：DONE 是绿色"完成"，FAILED 是红色"失败"——已验证 DONE 绿色；库中无 PENDING/RUNNING/FAILED 记录，其余三态待有数据后补验
- [x] 进度列显示 `3/3` 这种分数，且进度条满格
- [x] 有一列"耗时"，显示秒或分钟
- [x] 点任意一行 → 跳到 `/#/report/<id>`（实测跳到 /#/report/11）
- [x] 点"刷新"按钮，出现 loading 后重新加载
- [ ] 关掉"自动刷新"开关，有进行中任务时进度不再自动跳（可以上传一个大文件观察）——后端为同步审计，任务创建即 DONE，库中不存在 RUNNING 任务，无法观测

## 6. 卡住怎么办

| 症状 | 原因 | 处理 |
|---|---|---|
| 表格一直是"还没有审计记录" | 后端库是空的 | 先去 F1 传文件；`curl /api/audit/tasks` 确认有数据 |
| 点行没反应 | `@row-click` 被列上的按钮拦掉 | 按钮里已加 `.stop`，确认没删掉 |
| 进度不动的 | 后端是同步审计，任务一创建就是 DONE，看不到 RUNNING | 正常；`RUNNING` 只在将来改成异步时才会出现 |
| 时间显示 `NaN` | 后端返回的 `createdAt` 为空 | 后端 `audit_task.created_at` 有默认值，若为空则是建表问题 |
| 报 `api.tasks is not a function` | api.js 没写 `tasks` 方法 | 回到 F0.4.1 核对 api.js |
